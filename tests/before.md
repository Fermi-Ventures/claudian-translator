# A standard as returned

This is the regression text for the translator. Every sentence below was sent back by a human reviewer or flagged by the lane, and the README's table holds the rewrite that replaced each one. Run `node tools/translate.mjs tests/before.md` and compare.

## Copies

A copy you did not write is still only evidence of its moment — re-derive before relying. The writer's rule cannot govern documents its audience did not write. A hand-copy is a signal — a derivation path is missing.

## Rendering

Render from data. Code-shaped architecture is invisible and therefore drifts. The forcing function is the machine census.

## Sites

The schema column with its constraints is one site. Each executor's switch or branch chain is another. The chain counts as a site because it is the tell — the defect this rule exists to find.

## State machines

If an attribute's legal next value depends on its current value and it meets the threshold below, it is a state machine: it belongs to a named machine definition from the first migration in which it qualifies, and a nested or parallel lifecycle is expressed in the definition, never as a loop or branch in an executor. Crossing the threshold is a design change, announced at review — never folded into a refactor.

## Reasons and censuses

A reason that keeps recurring is a backlog item wearing a footnote's clothes. The census is a burn-down, not an amnesty.

## The lane

Standards, specs and agent briefs written inside a long AI-assisted conversation come out readable only to that conversation. Two lanes and one loop. The linter counts and remembers. The models read and discover. The reviewer decides.

## Controls

Do not remove a load-bearing wall without a structural engineer's sign-off. The migration is what proves the trigger was dropped. Every cache declares its invalidation trigger or TTL at the declaration site.
